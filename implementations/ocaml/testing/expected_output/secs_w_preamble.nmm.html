¶ 1.1

¶ 1.1

This is a no-markup-markup document, sporting the following cool features:

(1)

Emphasized text spanning multiple lines in the source code without breaking a sweat.

(2)

Bullet lists:

─

Here is one bullet item.

─

Here is another one.

(3)

Numbered lists with labels that are either

(a)

automatic, or

(*)

custom.

Furthermore, each item can be named and referred to:

(b)

The named item can be referred to anywhere in the document.

(c)

When referring to (b) above in a local manner (which is default), any common initial path shared between the location of the referring expression and the location of its referent will be omitted. The same applies with respect to (†) below.

(†)

Of course, items with custom labels can also be named!

Due to the feature mentioned in (3)(c), a local reference to (3)(b) or (3)(†) occurring elsewhere may appear differently.

(4)

Displayed lines of text suitable for mathematical equations, which are either

(a)
automatically labeled (and named),
(+)
custom labeled (and named), or,
unlike (a) above, unlabeled.

¶ 2.3

¶ 2.3

DEFINITION We say that Γ ⊨ φ just in case every model of Γ is a model of φ.

¶ 2.4

Provability

DEFINITION (Provability) We say that Γ ⊢ φ just in case there is a proof from Γ to φ.

¶ 2.5

¶ 2.5

FACT For every sentence φ and set of sentences Γ, if Γ ⊨ φ then Γ ⊢ φ.
