Referring to named items under REFERENCES

Eric Johannesson

Given a named item under REFERENCES, say with the the name ‘ITM:Euler’, what should the cross reference ‘[ITM:Euler]’ look like? Assuming it is the first item on the list, one could either go for

(1)

‘REFERENCES(1)’ (or something similar), or

(2)

my preferred solution: ‘[1]’, with item labels under REFERENCES rendered as ‘[1]’, ‘[2]’, etc.

Having implemented (2), I can refer to [1] of REFERENCES and [2] of REFERENCES below, as just indicated. I think it looks quite nice. For good or bad, it is also familiar from the default in LaTex.

In the future, one would perhaps like to implement som fancier bibliography system compatible with standard bibliography tools (e.g. zotero). But for now, I think this would suffice.

REFERENCES

[2]

Tarski, Alfred, and Andrzej Mostowski, and Raphael M. Robinson (1953): Undecidable Theories; North-Holland Publishing Company; Amsterdam.
